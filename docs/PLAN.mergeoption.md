# Plan for Updating the Merge Option to "Merge to New"

## Overview
The current implementation provides a bulk‑action named **Merge** that:
- Appears in the bulk‑actions dropdown (defined in `class-Base.php`).
- Shows an input box labelled *"into:"* (generated by `class-HTML.php`).
- Executes the merge logic in `class-Handlers.php` via the `merge_terms` method.

The goal is to rename this option to **"Merge to New"** and adjust the UI/logic to reflect the new wording while preserving existing functionality.

3. **Update Handler Switch**
